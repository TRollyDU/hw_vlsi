Bài 10: Chuyển đổi nhị phân và Gray 4 bit
Module: bin_gray

1. Overview
Chuyển đổi nhị phân và Gray 4 bit.

2. Scope
Hai đường chuyển đổi tổ hợp độc lập, độ rộng cố định 4 bit.
Testbench dùng timescale 1ns/1ps.

3. Functional spec
I/O pins:
| Name | Bitwidth | Description |
| bin_in | 4 | Input: Số nhị phân cần chuyển sang Gray. |
| gray_in | 4 | Input: Mã Gray cần chuyển sang nhị phân. |
| gray_out | 4 | Output: Mã Gray chuyển từ bin_in. |
| bin_out | 4 | Output: Số nhị phân chuyển từ gray_in. |

Quy tắc hoạt động:
gray_out=bin_in XOR (bin_in>>1).
bin_out[3]=gray_in[3]; bin_out[k]=bin_out[k+1] XOR gray_in[k], k=2..0.

4. Dataflow
bin_in đi qua XOR bit kề tới gray_out; gray_in qua chuỗi XOR từ MSB tới bin_out.

5. Test plan
- Duyệt đủ 16 mã mỗi chiều.
- Kiểm tra chuyển đổi vòng bin -> Gray -> bin.
