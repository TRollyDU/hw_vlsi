Bài 05: Bộ giải mã 3–8
Module: dec3_8

1. Overview
Bộ giải mã 3–8.

2. Scope
Tổ hợp, ngõ ra one-hot active-high, không enable.
Testbench dùng timescale 1ns/1ps.

3. Functional spec
I/O pins:
| Name | Bitwidth | Description |
| a | 3 | Input: Địa chỉ nhị phân 3 bit. |
| y | 8 | Output: Các ngõ ra giải mã one-hot, active-high. |

Quy tắc hoạt động:
Chỉ y[a]=1, các bit còn lại bằng 0.

4. Dataflow
a qua giải mã nhị phân thành bus y one-hot.

5. Test plan
- Duyệt đủ 8 giá trị đầu vào.
