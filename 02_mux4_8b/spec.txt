Bài 02: Bộ dồn kênh 4:1 dữ liệu 8 bit
Module: mux4_8b

1. Overview
Bộ dồn kênh 4:1 dữ liệu 8 bit.

2. Scope
Mạch tổ hợp, dữ liệu không dấu.
Testbench dùng timescale 1ns/1ps.

3. Functional spec
I/O pins:
| Name | Bitwidth | Description |
| d0 | 8 | Input: Dữ liệu của kênh 0. |
| d1 | 8 | Input: Dữ liệu của kênh 1. |
| d2 | 8 | Input: Dữ liệu của kênh 2. |
| d3 | 8 | Input: Dữ liệu của kênh 3. |
| sel | 2 | Input: Chỉ số kênh cần chọn, từ 0 đến 3. |
| y | 8 | Output: Dữ liệu của kênh được chọn. |

Quy tắc hoạt động:
sel=0/1/2/3 chọn d0/d1/d2/d3 tương ứng.

4. Dataflow
Bốn bus dữ liệu đi vào mux; sel điều khiển bus nối tới y.

5. Test plan
- Kiểm tra cả 4 kênh với dữ liệu khác nhau.
- Thử dữ liệu 00, FF và dữ liệu giả ngẫu nhiên.
