Bài 03: Bộ dồn kênh 8:1
Module: mux8

1. Overview
Bộ dồn kênh 8:1.

2. Scope
Tám ngõ vào 1 bit, tổ hợp.
Testbench dùng timescale 1ns/1ps.

3. Functional spec
I/O pins:
| Name | Bitwidth | Description |
| d | 8 | Input: Tám kênh dữ liệu 1 bit, từ d[0] đến d[7]. |
| sel | 3 | Input: Chỉ số kênh cần chọn, từ 0 đến 7. |
| y | 1 | Output: Bit dữ liệu của kênh được chọn. |

Quy tắc hoạt động:
y=d[sel].

4. Dataflow
sel chọn một bit từ d và đưa trực tiếp tới y.

5. Test plan
- Duyệt đủ 256 mẫu dữ liệu và 8 lựa chọn kênh.
