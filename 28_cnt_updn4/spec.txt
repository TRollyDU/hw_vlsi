Bài 28: Bộ đếm lên/xuống 4 bit
Module: cnt_updn4

1. Overview
Bộ đếm lên/xuống 4 bit.

2. Scope
Cạnh lên clk, reset bất đồng bộ mức cao; đếm modulo 16.
Clock mặc định 50 MHz, chu kỳ 20 ns. Testbench dùng timescale 1ns/1ps.

3. Functional spec
I/O pins:
| Name | Bitwidth | Description |
| clk | 1 | Input: Clock lấy mẫu tại cạnh lên, mặc định 50 MHz (chu kỳ 20 ns). |
| rst | 1 | Input: Reset bất đồng bộ mức cao; ưu tiên cao nhất. |
| en | 1 | Input: Cho phép cập nhật khi bằng 1; bằng 0 giữ giá trị. |
| up | 1 | Input: Bằng 1 đếm lên; bằng 0 đếm xuống. |
| q | 4 | Output: Giá trị bộ đếm modulo 16. |

Quy tắc hoạt động:
rst=1 xóa q. Tại cạnh lên khi rst=0,en=1: up=1 tăng 1, up=0 giảm 1. en=0 giữ. Biên 15->0 khi lên, 0->15 khi xuống.

4. Dataflow
up chọn bộ tăng/giảm; en cho phép ghi vào thanh ghi q.

5. Test plan
- Đếm xuống từ 0 qua biên.
- Đổi hướng để đếm lên qua 15.
- Giữ enable thấp và reset khi đang đếm.
